核心判定原则

  1. 评价对象是当前 ASR 错误是否使合理读者形成与说话者原意不同的实质性理解，而不是字面是否相同。
  2. S1-S4 是互补而非互斥的语义视角；同一错误可以同时改变多个维度，例如否定删除既改变命题真值，也改变逻辑极性。
  3. 专名拼写、空格或词形不同，如果仍指向同一对象或概念，应判为仅形式差异；不能仅凭字符串不同判为语义改变。
  4. 能够识别话题不等于能够恢复原意；关键实体、数值、条件、角色、立场或结论仍不确定时，最多是部分可恢复。
  5. C1 只评价 hypothesis 侧证据是否足以恢复 reference 意图，不评价该信息在任务中的重要性。
  6. C2 评价合理读者最终理解的偏差；语义机制的存在与后果严重程度必须分别判断。
  7. 证据优先引用最短且足够支持答案的原文片段，并保留原始空格、大小写和标点。

01 G1 · 门控 对齐有效性 4 个选项

reference span 与 hypothesis span 是否位于同一局部 ASR 编辑位置，因而可以进行语义比较？

判定对象判断局部位置和边界是否对应，不判断二者含义是否相似。

有效

两个 span 对应同一局部编辑位置，边界足以支持比较。含义差异很大仍可属于有效对齐。

  • 同一局部编辑
部分有效

大体对应同一位置，但一侧边界多包含或少包含了邻近成分；核心差异仍可识别。

  • 边界有偏差但可比较
无效

两个 span 来自不相关位置，或边界错误到无法确认当前高亮是否是真实 ASR 编辑。

  • 配对位置错误
  • 边界无法定位
不可评分

现有字段不足以判断对齐是否有效。

  • 对齐证据不足

无效

  • “did not improve→improved”含义相反，但若出现在同一谓词位置，对齐仍是有效。
  • 两个 span 实际来自句中不同位置时才属于无效。
02 G2 · 门控 证据充分性 2 个选项

reference 意图、hypothesis 表达和可见上下文是否足以可靠判断当前错误的语义后果？

判定对象判断证据能否支持后续问题；不因任务困难而自动判为不可评分。

可评分

  • 参考文本有问题
  • 必要上下文缺失
  • 原意存在实质歧义
  • 多种解释无法仲裁

03 S1 · 语义结构 指称与词义 5 个选项

当前错误是否改变了表达式所指的对象、概念、类别、属性、专业术语或具体值？

判定对象比较 who/what/value：人、地、组织、产品、术语、类别、属性、数字、日期、单位、版本和数量。

保持不变

适用该维度，且同一对象、概念、属性或值被保留。

  • 指称保持
  • 概念或属性保持
仅形式差异

拼写、空格、词形或发音转写不同，但普通读者仍能唯一识别同一对象、概念或值。

  • 同一对象的拼写变体
  • 空格或词形变体
语义改变

对象身份、词义、类别、属性、术语或值被替换、删除、新增，或不再能被唯一识别。

  • 指称对象改变
  • 词义或类别改变
  • 专业术语改变
  • 属性改变
  • 数字或时间改变
  • 单位或版本改变
  • 对象无法唯一识别
不确定

现有证据无法可靠确定两种表达是否指向同一对象、概念或值。

  • 指称词义无法确定
不适用

当前错误不涉及可识别的指称对象、词义单位、属性或值。

  • 该维度不适用

判定对象比较命题如何成立和如何被组织：polarity、possibility、certainty、scope、condition、comparison、tense/aspect、focus 和 perspective。

  • 逻辑识解无法确定

07 C1 · 语境解释 上下文可恢复性 4 个选项

只根据 ASR hypothesis 和读者可见的上下文，不使用 reference 独有信息，普通读者能否唯一且可靠地恢复说话者原意？

判定对象执行反事实读者测试；评价恢复可能性，不评价被恢复信息的重要性。

完全可恢复

hypothesis 和上下文只支持一个合理解释，且该解释与 reference 意图一致；读者无需看到 reference。

  • 上下文唯一确定原意
  • 表面变体仍可唯一识别
部分可恢复

能够恢复大致主题或部分内容，但关键对象、事实、值、关系、条件、立场或结论仍不确定。

  • 仅能恢复大致主题
  • 关键细节仍缺失
不可恢复

hypothesis 支持错误理解，或支持多个实质不同解释，无法可靠恢复 reference 意图。

  • 错误解释更自然
  • 存在多个实质解释
  • 无上下文纠正
不可评分

允许使用的上下文本身不足，或原始意图不明确，无法评价恢复程度。

  • 上下文证据不足

证据来源

hypothesis_span · hypothesis_text · history · suffix

强制证据答案

完全可恢复 · 部分可恢复 · 不可恢复

边界示例

  • 拼写不同但上下文只可能指向同一专名，判为完全可恢复。
  • 知道在讨论某模型但无法确定具体型号，判为部分可恢复。
08 C2 · 语义后果 读者理解后果 5 个选项

合理读者阅读 ASR hypothesis 与可见上下文后，相比说话者原意会产生多大程度的理解偏差？

判定对象评价最终解释差异，而不是字面编辑距离、错误显眼程度或声学可混淆性。

无影响

读者最终理解与原意一致；差异仅为形式或已被上下文唯一恢复。

  • 最终理解一致
  • 纯形式差异
轻微影响

局部表达或非关键信息略有偏差，但核心事实、对象身份、术语、值、角色、逻辑条件和立场不变。

  • 非关键信息局部偏差
实质影响

至少一个事实、对象身份、关键术语、值、角色关系、逻辑条件、立场或结论可能被错误理解或无法确定。

  • 事实或事件可能误解
  • 对象或术语可能误解
  • 数值或属性可能误解
  • 角色或关系可能误解
  • 逻辑条件可能误解
关键影响

错误反转主要结论、关键否定、核心实体、责任主体、关键数字、安全信息或其他高风险含义。

  • 主要结论反转
  • 高风险信息改变
不可评分

当前证据不足以可靠判断理解偏差。

  • 影响程度无法确定
